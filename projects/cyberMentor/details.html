Project Overview

CyberMentor NLP is an intelligent cybersecurity platform that combines natural language processing and machine learning to analyze system logs and detect potential cyberattacks in real time. The system assists security analysts by providing contextual recommendations aligned with recognized cybersecurity frameworks such as MITRE ATT&CK.

Key Features

  • AI-driven analysis of raw system and security logs
  • NLP-based attack detection using transformer models
  • Real-time identification of suspicious activities
  • Context-aware security recommendations
  • Integration with MITRE ATT&CK knowledge framework
  • Interactive Streamlit dashboard for monitoring threats
  • Visual analytics for detected attacks and risks
  • Containerized deployment for easy installation and scalability
  • Modular and extensible system architecture
  • User-friendly interface for security analysts

Technical Implementation

The system is developed in Python and leverages NLP techniques for log preprocessing and analysis. A transformer-based model (DistilBERT) is used to classify and detect cyberattacks from textual log data. Detected threats are enriched using a Retrieval-Augmented Generation (RAG) knowledge base to generate contextual security recommendations. A large language model (Qwen), sourced from Hugging Face, is integrated to enhance threat interpretation and produce human-readable security guidance and response recommendations. The frontend is built with Streamlit to provide an interactive real-time monitoring dashboard, and the application is designed for containerized deployment to ensure ease of maintenance and scalability.
