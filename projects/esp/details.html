Project Overview

The IoT Home Security System is a comprehensive solution designed to enhance residential security through the integration of IoT sensors, a serverless backend, and a secure cloud-based dashboard. The system provides real-time monitoring, alerting, and data analytics to ensure the safety of homes.

Key Features

  • ESP32-based IoT sensors for motion detection, door/window status, and environmental monitoring
  • Serverless backend architecture using AWS Lambda for scalable event processing
  • Real-time data transmission via MQTT protocol to ensure low-latency communication
  • Secure cloud dashboard for remote monitoring and control of home security system
  • Automated alerts and notifications via SMS and email for security events
  • Data logging and historical analysis of sensor data for trend identification
  • User authentication and role-based access control for enhanced security
  • Modular design allowing easy addition of new sensors and features
  • Energy-efficient operation with low power consumption IoT devices
  • User-friendly interface for seamless interaction with the security system

Technical Implementation

The system is built around an ESP32 microcontroller connected to multiple sensors, including gas, flame, water leakage, and RFID modules. Sensor data is transmitted securely in JSON format to a Cloudflare Worker, where HMAC SHA-256 verification, device authentication, and data validation are performed. Validated data is stored in a Supabase PostgreSQL database, which serves as the central cloud data layer. The administrative dashboard is developed using React, Vite, and Tailwind CSS, hosted on Firebase Hosting, and secured with Firebase Authentication and email-based multi-factor authentication (MFA). All secrets and credentials are managed using Cloudflare Secrets to ensure strong security and system integrity.
