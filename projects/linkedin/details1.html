Project Overview

JobMarket is a data engineering and analysis project focused on extracting trends and insights from professional profiles on LinkedIn in the maintenance and reliability sector. The system scrapes profile data, segments the market using clustering techniques, and provides actionable insights for recruitment and market analysis.

Key Features

  • Automated data extraction from LinkedIn profiles using Apify
  • Data preprocessing and cleaning for accurate analysis
  • Clustering of profiles using K-Means to identify similar groups
  • Market segmentation based on professional experience and skills
  • Visualization of years distribution and frequent words from profiles
  • Pie chart analysis for premium vs verified users
  • Feature-based profile visualization for deeper insights
  • Interactive analysis using Jupyter Notebook
  • Actionable insights for recruitment and workforce planning
  • Exportable graphs and charts for reporting purposes

Technical Implementation

The system uses Python with Apify for LinkedIn data scraping and extraction. Data is processed and analyzed using Pandas and NumPy, with clustering performed via the K-Means algorithm to segment similar profiles. Jupyter Notebook is used for interactive analysis and visualization, including graphs of years distribution, frequent words, pie charts for user types, and feature-based profile visualizations. This workflow allows end-to-end insights from raw data to actionable conclusions.
