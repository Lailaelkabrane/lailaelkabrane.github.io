Project Overview

PredictEnergy-MA is a university project focused on predicting Morocco's electricity consumption using Big Data and Artificial Intelligence. The system leverages public datasets from the World Bank and World Bank Climate Data (1990–2023) to model energy evolution in the country, integrating climatic parameters and energy mix transformations.

Key Features

  • Collection and integration of Moroccan energy and climate data
  • Structured data pipeline: raw → bronze → silver → gold layers
  • Data processing and aggregation using PySpark
  • Forecasting models including Prophet and LSTM for future consumption
  • Visualization of actual and predicted consumption in Streamlit
  • Error analysis and model performance evaluation
  • Containerized environment using Docker
  • Storage and deployment using Hadoop HDFS
  • Live deployment on Hugging Face Spaces

Technical Implementation

The project is developed using a Big Data pipeline for handling large-scale energy and climate datasets. PySpark is used for data cleaning, transformation, and aggregation across multiple layers of the pipeline. Time series forecasting models (Prophet and LSTM) are applied to estimate future electricity consumption. The results are visualized in an interactive Streamlit dashboard. The system is containerized with Docker, stores data in Hadoop HDFS, and is deployed on Hugging Face Spaces for easy access.
