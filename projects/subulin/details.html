Project Overview

Subul IN is an AI-powered Chrome extension for LinkedIn, built as a premium feature of Smartovate's Subul e-learning platform. It was developed as my final year project (PFE) for the Master's in Data Analytics and Artificial Intelligence, defended in July 2026 under the academic supervision of Pr. Moncef Boughrous. The extension helps professionals grow their LinkedIn presence with AI-generated posts, profile optimization, career gap analysis, connection scoring, and a retrieval-augmented chat assistant, all running directly inside the LinkedIn interface.

Key Features

  • AI-generated LinkedIn posts tailored to the user's voice and goals
  • Profile optimization and scoring against industry benchmarks
  • Career gap analysis with personalized rewrite suggestions
  • Network connection scoring to prioritize high-value outreach
  • Retrieval-augmented (RAG) chat assistant for LinkedIn strategy questions
  • Multilingual semantic industry-alignment scoring using MiniLM embeddings
  • Secure JWT-based authentication between the extension and backend
  • Identity-safe content generation with server-side sanitization to prevent data leaks

Technical Implementation

The extension is built on Chrome's Manifest V3 architecture and communicates with a FastAPI backend deployed on Azure App Service. Content generation runs on fine-tuned Azure OpenAI models (GPT-4o-mini), including a dedicated post-generation model selected for its Pareto-optimal balance of compliance, latency, and cost across the models evaluated. A LangGraph-based agentic workflow orchestrates the different AI features, while Azure Cosmos DB stores user and session data. Profile and gap-analysis features use multilingual MiniLM embeddings for semantic (rather than purely keyword-based) industry matching, rolled out safely behind a feature flag with dual logging to compare keyword and semantic scores in production.

Impact

In production, Subul IN processed thousands of AI requests for dozens of active users with a success rate close to 99%, demonstrating both the reliability of the pipeline and the real-world value of combining agentic AI workflows with a lightweight, in-browser user experience.
