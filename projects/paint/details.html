Project Overview

Artelle is an interactive virtual painting system that enables users to draw on a digital canvas using only hand gestures. By combining computer vision and gesture recognition, the application provides a natural and intuitive drawing experience without the need for physical input devices such as a mouse or stylus.

Key Features

  • Real-time hand detection and tracking using a webcam
  • Gesture-based drawing without physical contact
  • Dynamic color selection through hand gestures
  • Virtual brush and eraser controlled by finger positions
  • Live canvas rendering with smooth stroke drawing
  • Tool switching using intuitive hand gestures
  • Hands-free creative interaction
  • Low-latency performance for real-time feedback
  • User-friendly and intuitive interface
  • Extensible design for adding new gestures and tools

Technical Implementation

The system is developed in Python and leverages OpenCV for real-time video processing and canvas rendering. MediaPipe is used for accurate hand landmark detection and gesture tracking, enabling precise interpretation of finger movements. The gesture recognition logic maps specific hand positions to drawing actions, color selection, and tool switching. The application processes video frames in real time to ensure smooth interaction and responsive virtual painting.
