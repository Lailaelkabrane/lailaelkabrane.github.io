Project Overview

CV Booster is an AI-powered CV optimization tool built as part of the SUBUL platform during my internship at Smartovate, alongside Subul IN. It guides users through a 5-step flow — Import, ATS Score, Enrich, Boost, and Result — to turn a raw CV into an ATS-optimized document, while automatically pulling in achievements the user already has on the SUBUL e-learning platform.

Key Features

  • Drag-and-drop CV import (PDF) with instant AI analysis
  • Real-time ATS scoring engine (0–100) evaluating key sections, work experience, contact info, professional summary, technical skills, CV length, keyword matching, and languages
  • Explainable scoring: for each criterion, the tool shows exactly why a score was given, what was detected versus missing, and the precise fix needed to gain points
  • Guided completion flow for missing required sections (e.g. languages) with quick-add suggestions
  • Automatic enrichment from the user's SUBUL profile: completed labs, validated certifications, and a positioning quiz score used to detect the user's domain and expertise level
  • One-click "Boost" that rewrites and restructures the CV, recalculating the ATS score live
  • Multiple export formats (ATS Optimized, Basic/Classic, Modern/Creative) generated as downloadable .docx files without needing to regenerate the CV from scratch

Technical Implementation

The backend is built with Python and FastAPI, using Azure OpenAI models to analyze CV content, generate the explainable ATS breakdown, and rewrite sections such as the professional summary with stronger, keyword-rich language. Enrichment data (labs, certifications, quiz scores) is fetched directly from the SUBUL platform's user profile and merged into the CV content. The final boosted CV is rendered into multiple .docx templates (ATS-safe single-column layout, classic, and modern formats) that can be downloaded instantly.

Impact

In testing, CV Booster took CVs with low ATS scores (around 39/100) and consistently boosted them into the 90+ range by filling missing sections, improving keyword coverage, and strengthening the professional summary, directly increasing the chances of passing automated recruiter filters.
